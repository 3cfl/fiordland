Getting help

Where to ask, and what to include so people can help.

Where to ask

  • Wiki: guides and fixes written by users. Search it first.
  • Help desk: ask a question on the wiki. Every wiki page also has a Discussion tab.
  • GitHub issues: bugs in Fiordland, tawaki or the installer.
  • Arch Wiki: Fiordland uses the Arch repos, so most of it applies.

What to include

  • What you did, what you expected, and what happened instead.
  • The exact error text. Copy it, do not retype it.
  • Your hardware, especially the GPU.

This prints a hardware summary you can paste:

inxi -Fxz

For errors from the current boot:

journalctl -b -p err --no-pager | tail -50

Do not paste

Passwords, Wi-Fi keys or anything from /etc/shadow. inxi -z already hides serial numbers and IP addresses.
