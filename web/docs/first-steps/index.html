First steps

What to do after the first boot.

Connect to the internet

Click the network icon in the panel and pick your Wi-Fi. A cable works without any setup.

Update once

The ISO may be a few days old. Open a terminal and run:

tawaki update

It asks for your password, then updates the system, Flatpaks and AUR packages together.

Install your apps

Use the package manager from the terminal:

tawaki install firefox steam discord

i is a shortcut for tawaki install. More in Installing apps.

Already set up for you

  • Graphics drivers for your GPU, Vulkan and 32-bit libraries for Steam and Wine.
  • Flathub, so Flatpak apps work straight away.
  • Printing, with network printers found automatically.
  • A firewall (ufw) that blocks incoming connections.
  • Bluetooth, power profiles, firmware updates and zram swap.
  • Snapshots before every update, so a bad update can be undone.

Terminal basics

  • sudo runs a command as administrator. It asks for your own password.
  • Typing a command you do not have tells you which package provides it.
  • Ctrl+C stops a running command. Ctrl+Shift+V pastes in most terminals.
