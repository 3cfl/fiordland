Updates

Keep the system current and what to do when an update goes wrong.

Update

tawaki update

Run it every week or two. Fiordland is a rolling release: there are no big version upgrades, just regular small ones.

Before updating

  • Close games and apps that are running.
  • Keep the laptop plugged in.
  • Read what the update prints. Messages that start with ==> or warning: sometimes ask you to do something.

After a kernel update

Restart when it finishes. Until then, new USB devices and some drivers may not load.

When an update goes wrong

A snapshot is taken before every update. See Snapshots and rollback. If the desktop does not start, pick Arch kernel or safe graphics in the boot menu first.

Clean up

Old package downloads are cleared every week automatically, keeping the last three versions. To remove packages nothing uses any more:

sudo pacman -Rns $(pacman -Qdtq)
