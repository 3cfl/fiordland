Updates

Keep the system current and what to do when an update goes wrong.

Update

tawaki update

Run it every week or two. Fiordland is a rolling release: packages update in small steps, and new releases arrive the same way.

New releases

A new ISO is only for new installs. An installed system gets the same changes through tawaki update: new default packages, settings and fixes are applied once, inside the update, after the pre-update snapshot. When the release number changes, the update prints it with a short list of what's new, for example Fiordland 0.9.0 -> 1.0.0.

cat /etc/os-release

shows the current release. fiordland-migrate --list shows which release changes are applied. A change that fails is reported, logged in /var/log/fiordland-migrate.log and tried again on the next update.

Before updating

  • Close games and apps that are running.
  • Keep the laptop plugged in.
  • Read what the update prints. Messages that start with ==> or warning: sometimes ask you to do something.

After a kernel update

Restart when it finishes. Until then, new USB devices and some drivers may not load.

When an update goes wrong

A snapshot is taken before every update. See Snapshots and rollback. If the desktop does not start, pick Arch kernel or safe graphics in the boot menu first.

Clean up

Old package downloads are cleared every week automatically, keeping the last three versions. To remove packages nothing uses any more:

sudo pacman -Rns $(pacman -Qdtq)
