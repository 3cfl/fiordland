Installing apps

Find, install, update and remove apps with tawaki.

How it works

tawaki searches three places at once: the Arch repositories, Flathub and the AUR. It installs from the repos when it can, then Flathub, then the AUR. If a Flatpak would pull in a large runtime you do not have yet, it picks a prebuilt package instead.

Commands

tawaki install NAMEInstall an app. Short: i NAME
tawaki remove NAMERemove it, wherever it came from
tawaki updateUpdate everything. Short: up
tawaki search WORDSSearch all three sources
tawaki listList apps installed with tawaki
tawaki install NAME --from flatpakForce a source: pacman, flatpak or aur

Settings

Edit ~/.config/tawaki/config.toml to change the order or turn off the light-package check:

priority = ["pacman", "flatpak", "aur"]
prefer_light = true

About the AUR

AUR packages are build scripts uploaded by users. Nobody at Arch or Fiordland reviews them. Prefer repo and Flathub packages, and only install from the AUR when you trust the package.

Other tools still work

pacman, flatpak and paru are all installed. tawaki is a front end, not a replacement.
