Install Fiordland

Make a USB stick, boot it and run the installer.

What you need

  • A 64-bit PC. UEFI is recommended; older BIOS machines work too.
  • 4 GB of RAM at least, 8 GB or more is better.
  • 30 GB of disk. Either a whole disk, which is erased, or room next to Windows on a UEFI computer. Back up anything you want to keep.
  • To keep Windows: turn off Fast Startup and BitLocker (Device encryption) in Windows first, then shut down fully.
  • A USB stick of 4 GB or more, and an internet connection during the install.

Install

  1. Download the ISO

    Get it from the home page. The SHA-256 checksum is listed under the download button. On Linux, check it with:

    sha256sum fiordland-*.iso

  2. Write it to a USB stick

    On Windows use Rufus and pick DD image mode when it asks. On macOS or Windows, balenaEtcher also works. On Linux:

    sudo dd if=fiordland-*.iso of=/dev/sdX bs=4M status=progress oflag=sync

    Replace sdX with the USB stick. lsblk lists your drives. Picking the wrong one erases it.

  3. Boot from the stick

    Restart and press the boot menu key while the logo shows. It is usually F12, F11, F8, Esc or F2. Turn off Secure Boot in the firmware settings first; Fiordland's boot files are not signed yet.

  4. Run the installer

    The live desktop opens the installer by itself. Pick your language, keyboard, timezone, the disk (the whole disk, alongside Windows with a slider for the size, or partitions you choose, with a partition editor one click away), your account and a desktop. KDE Plasma is the default and the easiest switch from Windows. The review page lets you change the graphics driver and kernel before anything is written.

  5. Restart

    Packages download fresh, so the install takes 5 to 20 minutes. Remove the USB stick when the computer restarts.

If something goes wrong

  • The disk does not show up: in the firmware settings, change SATA mode from RAID or Intel RST to AHCI.
  • Black screen after the boot menu: pick Fiordland Linux (safe graphics).
  • Anything else: see the Troubleshooting page on the wiki.
