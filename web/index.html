Fiordland Linux

Arch-based, with its own package manager, installer and desktop shell. CachyOS kernel, Btrfs snapshots and Flathub set up from the start. Steam, Proton-CachyOS, MangoHud and gamescope come installed.

What's in it

tawaki

One command for the Arch repos, Flathub and the AUR. Installs from the cleanest source and skips Flatpaks that would pull in a large runtime.

~ tawaki search ncspot
[pacman] extra/ncspot 1.5.0-2
    Cross-platform ncurses Spotify client written in Rust
[flatpak] io.github.hrkfdn.ncspot 1.5.0 (ncspot)
    Cross-platform ncurses Spotify client
[aur] ncspot-git 1.3.1-1
[aur] ncspot-ncurses 1.5.1-1

rawaru

Graphical installer. Ranks mirrors, detects the GPU and offers dotfiles for each window manager.

crest

A Hyprland shell forked from Caelestia: bar, dashboard, launcher, lock screen and settings, themed for Fiordland.

⚡

CachyOS kernel

Default kernel, with the Arch kernel kept as a boot option.

Update manager. System and Flatpak updates in one window, with a snapshot taken first.
